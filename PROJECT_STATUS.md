# Khobragade Computer Service Centre CMS - Updated Build

## Admin modules
- Firebase Email/Password login and logout
- Protected admin dashboard
- Live dashboard counts
- Government Updates: Add/Edit/Delete/Search/Status/Featured
- Services: Add/Edit/Delete/Search/Category Filter/Status/Featured
- Categories: Add/Edit/Delete/Search
- Notifications: Breaking/Popup/Normal, Priority, Published/Draft, Edit/Delete
- Images: Firebase Storage upload + external URL fallback + gallery + delete
- Documents: Firebase Storage upload + external URL fallback + public library + delete
- YouTube: Firestore Add/Edit/Delete/Search
- Settings: business identity, contacts, social links and homepage text
- Analytics: total visitors, today visitors, live content counts, 14-day visitor chart

## Public sync
- Home page Featured/Published Services from Firebase
- Home page Published Government Updates from Firebase
- Breaking and Popup notifications from Firebase
- Home media section from Images and YouTube
- Services page live Firebase service section
- Documents page live Firebase document section
- Website settings auto-sync across public pages
- Visitor tracking to Firebase Analytics collections

Green, Yellow, Pink, Red, Blue, Black and White palette retained throughout Admin UI.
